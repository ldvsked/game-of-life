# Game of Life

## О проекте

Реализация классического клеточного автомата "The Game of Life", придуманного математиком Джоном Конвеем в 1970 году. Проект представляет собой интерактивную визуализацию в терминале с использованием библиотеки ncurses.

## Игровой процесс

- **Поле**: замкнутый тор (прямоугольник 80×25 клеток, где правая граница переходит в левую, а верхняя — в нижнюю)
- **Клетки**: могут быть живыми (1) или мертвыми (0)
- **Правила**:
  - Живая клетка с 2-3 живыми соседями продолжает жить
  - Мертвая клетка с 3 живыми соседями оживает
  - В остальных случаях клетка умирает или остается мертвой

## Управление

- **A/a** — увеличение скорости
- **Z/z** — уменьшение скорости  
- **Пробел** — завершение программы

## Технические особенности

- **Язык**: C
- **Библиотека**: ncurses для отрисовки и обработки ввода
- **Память**: динамическое выделение под двумерный массив
- **Ввод**: инициализация через stdin (перенаправление из файла)

## Запуск

```bash
cd src
# Компиляция
gcc -o game_of_life game_of_life.c -lncurses

# Запуск с файлом инициализации
./game_of_life < integral.txt
```

## Начальные конфигурации

В проекте подготовлено 5 файлов с классическими паттернами:
- Устойчивые фигуры (блок, улей)
- Периодические фигуры (мигалка, тоads)
- Двигающиеся фигуры (глайдер)
- Ружья (glider_gun)
- Долгожители

## Архитектура

- **Модульность**: отдельные функции для каждого действия
- **Отсутствие системных вызовов**
- **Защита от утечек памяти**
- **Инкапсуляция логики игры**

Проект демонстрирует навыки работы с динамической памятью, обработкой пользовательского ввода в реальном времени и реализацией клеточных автоматов.
